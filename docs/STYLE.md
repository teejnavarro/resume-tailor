# STYLE.md: How Tyrone's resumes should sound

> Every tailored resume is checked against this file before the PDF is made.

## Voice: polished and professional
Chosen by the owner on 2026-10-19 (replaces "plain and direct", 2026-10-16).

Reference bullet:
> Re-engineered 25 report queries for the new warehouse and validated every rebuilt report against pre-migration totals.

What makes it work:
- Opens with a strong, specific verb (designed, delivered, validated, reduced).
- Names the real things: tools, counts, objects.
- One idea per bullet. A result is stated when the master file has it, never invented.
- Formal enough for a recruiter, still something I'd say out loud in an interview.

## Rules
1. **Lead with the verb**, in past tense for past roles and present tense for the current role. Drop "I" in the final resume (Harvard style); the master file may use "I" in notes.
2. **Concrete over impressive.** Numbers, tools and named things beat adjectives.
3. **Only numbers I can defend.** If it isn't in the master file, it doesn't go in. Interview-only facts (e.g. a loss figure I remember but can't document) stay off the resume.
4. **Short.** Aim for one line, two at most. Cut "in order to", "various", "successfully".
5. **No em dashes, no semicolon chains, no rule-of-three lists for rhythm.** Vary how bullets start.
6. **No stacked qualifiers** ("highly", "extremely", "deeply").
7. **Context only when it changes the meaning.** "After a reorg cut the team from six to three" earns its place; "in a fast-paced environment" doesn't.
8. **Honest labels.** Pilots are called pilots. AI-assisted work says so. Skills I can't be quizzed on (the master file marks which) never appear in the skills section.
9. **End every bullet with a full stop.** Same for every bullet on the page, so nothing looks unfinished.

## Banned words and phrases
Never use these (owner can add more):

spearheaded · leveraged / leveraging · utilize / utilized · synergy · dynamic · passionate · results-driven · cutting-edge · robust · seamless / seamlessly · delve · empower / empowered · streamline / streamlined · impactful · actionable insights · strategic decision-making · meticulously · effectively and sensitively · optimal · proven track record · in today's fast-paced… · go-to person · thought leader · game-changer · best-in-class · world-class · drive / drove (as in "drove results") · stakeholders (as a vague catch-all; name the team instead) · data-driven (as filler)

Plain swaps:
| Instead of | Write |
|---|---|
| spearheaded | led |
| leveraged / utilized | used |
| streamlined | cut, simplified, replaced (and say what) |
| actionable insights | the actual finding or decision |
| stakeholders | the actual team: the pricing team, QC reviewers, data engineering |
| ensured | checked, made sure (or show how) |

## Before → after examples
- ❌ "Meticulously ensured data integrity across all reporting assets."
  ✅ "Checked each rebuilt report against totals saved before the switch."
- ❌ "Designed and implemented an innovative solution to improve inventory accuracy."
  ✅ "Set up a nightly query that compares shelf counts to the stock system and lists the gaps by store."
- ❌ "Partnered with cross-functional stakeholders to drive alignment."
  ✅ "Met the finance team weekly until both teams used one definition of net sales."
